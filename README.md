# dth-sfp

The WHO **Digital transformation handbook for reporting substandard and falsified medical products** (2026, ISBN 9789240120747, IRIS 187cabc7), as an L2 Digital Transformation Handbook on [smart-ra](https://github.com/litlfred/smart-ra), [dth-sc](https://github.com/litlfred/dth-sc), [dth-pc](https://github.com/litlfred/dth-pc), [dth-hrh](https://github.com/litlfred/dth-hrh), and [smart-base](https://github.com/litlfred/smart-base): narrative validated against the glossaries, DAK components (personas, user scenarios, BPMN 2.0 workflows, DMN 1.3 decision tables, core data elements, requirements, and indicators), and linked to the DPI-H ArchiMate model.

- Working document: `folio/dth-sfp/`, seeded from the L1 entry [`who-iris/library/9789240120747-eng`](https://github.com/litlfred/who-iris/tree/main/library/9789240120747-eng).
- Substandard and falsified medical products reporting glossary: `glossary/dth-sfp.glossary.json` (`glossary/dth-sfp/dth-sfp.skos.jsonld` + `glossary/dth-sfp/index.md`).
- Business processes (BPMN 2.0): `processes/SF-REP-001.bpmn` .. `processes/SF-REP-006.bpmn`.
- Decision tables (DMN 1.3): `decisions/SFR-DT-01.dmn` .. `decisions/SFR-DT-04.dmn`.
- Plan: [`docs/workplan.md`](docs/workplan.md) (`litlfred/dth-sfp#1`).
- L1 normative coverage: [`docs/l1-coverage.md`](docs/l1-coverage.md) (`folio/dth-sfp/l1-coverage.json`).
- Agent guidance: [`AGENTS.md`](AGENTS.md).

This is a fork of WorldHealthOrganization/dth-sfp. Work happens here; nothing is pushed upstream without the owner's say-so.
